# Kwords

Kwords is a single-file word-of-the-day web app for ages 3 and 4. A child listens, traces, finds the picture, builds the word, then colours.

Open `index.html` in a browser. There is no build step.

Optional Supabase is configured in the `KWORDS_CONFIG` block at the top of `index.html`. Leave `supabaseUrl` and `supabaseKey` empty to run fully offline; progress stays on the device.
